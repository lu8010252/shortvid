# 短视频库 shortvid

自建的抖音式短视频网站,给孩子用的封闭内容池:只有你放进去的视频,没有推荐算法、评论、搜索和广告。

- 视频库 = 服务器上的文件夹,每个子文件夹自动成为「合集」,按集数顺序播放(第2集排在第10集前)
- 上下滑动切换,单击暂停,**双击进入全屏播放**(隐藏所有按钮,再双击或按返回键退出);合集记住看到哪一集哪一秒,播完自动接下一集
- 首页左上角「选合集」:随便刷全部 / 随机看某个分类 / 只看某个合集(按集数顺序播放)
- 合集页:搜索、分类、排序(最近观看/名称/集数/最新添加/没看完)、小图或列表两种显示
- 有 **TV 版**(投影/电视,遥控器操作,手机扫码登录),见下文
- 横屏视频在竖屏手机上自动转成横向播放,也可单个手动切换
- 孩子账号:可看的视频库、每日时长、连续观看休息提醒、禁止观看时段、是否允许「随便刷」
- 网页可添加到主屏幕(PWA),也有 Android App

## 部署(Docker)

镜像由 GitHub Actions 自动构建,支持 **amd64 / arm64 / armv7**,贴 compose 就能用:

```yaml
services:
  shortvid:
    image: ghcr.io/lu8010252/shortvid:latest
    container_name: shortvid
    restart: unless-stopped
    ports:
      - "8088:3000"
    environment:
      - TZ=Asia/Shanghai
      - ADMIN_USER=admin       # 仅首次启动创建管理员时有效
      - ADMIN_PASS=changeme123
      # - PUBLIC_URL=https://video.example.com   # 可选:电视扫码登录二维码里使用的地址
    volumes:
      - ./data:/data           # 数据库、封面
      - /video:/video:ro       # 左边改成服务器上存放短视频的目录(只读)
```

`docker compose up -d`,打开 `http://服务器IP:8088`,用管理员账号登录 → 我的 → 管理后台。
数据都在 `./data`,备份它即可。放在反向代理后面时,Nginx 建议加 `proxy_buffering off;`。

> 第一次推送后,到仓库的 Packages 里把 `shortvid` 设为 Public,就能免登录拉取。

## 使用流程

1. 管理后台 → 视频库管理 → 添加:选 `/video` 下的文件夹,后台自动扫描
2. 合集顺序不对?「合集排序」里手动调整、改标题,或一键恢复按文件名自动排序
3. 用户管理 → 添加孩子账号,设置可看的视频库和各种限制
4. 手机浏览器「添加到主屏幕」,或安装下面的 APK

手机对 H.265(HEVC) / MKV 的支持不一,建议用 H.264 的 mp4;后台会提示 H.265 的视频数量。

## 合集分类

管理后台 → 视频库管理 → 合集排序 → 每个合集右侧的「设分类」按钮。没设置的合集,分类默认就是视频库名称。

## TV 版(投影 / 电视)

- 到 Releases 下载 `shortvid-tv.apk`(适配 Android 8.0+,有遥控器入口);也可以直接用浏览器打开 `http://服务器地址/tv`。
- **第一次使用**
  1. 打开电视 App,屏幕上有一个二维码:用手机(同一个 WiFi)扫它,在手机页面里填服务器地址并提交,电视自动连接;也可以用遥控器直接输入。
  2. 电视进入后显示登录二维码:用手机相机/微信扫一扫,打开页面后(没登录先登录)点「确认登录」,电视自动进入。
     已经装了手机 App 的话,手机 App →「我的」→「扫码登录电视」可直接扫,不用再输密码。
- **遥控器**:方向键选择,确定键进入;播放时 ▲上一个 / ▼下一个、◀▶ 快退/快进 10 秒、确定键暂停、长按确定键(或菜单键)收藏、返回键退出。
- 每日时长、休息提醒、禁止时段等限制在电视上同样生效。
- 如果电视和手机访问服务器的地址不一样(例如电视用内网地址、手机在外网),可在服务端设置环境变量 `PUBLIC_URL=https://你的外网地址`,二维码会使用它。

## Android App

到 [Releases](../../releases) 下载 `shortvid.apk`(手机版,通用包,适配所有 CPU 架构)。首次打开输入服务器地址,之后自动进入;
「我的」页里可以「更换服务器地址」。App 内的返回键按层级返回(全屏 → 播放器 → 合集 → 首页),在首页再按两次才退出。App 只是加载服务器网页的外壳,服务端更新后无需重装。

重新打包 APK:Actions → Build APK → Run workflow,填版本号(如 `v1.1.0`);或推送 `v*` 标签。一次会同时生成手机版 `shortvid.apk` 和电视版 `shortvid-tv.apk`。
APK 使用仓库内固定的调试签名(`app/signing/debug.keystore`),保证新版本能直接覆盖安装,仅适合自用。

## 本地开发

```bash
npm install
DATA_DIR=./data VIDEO_ROOT=/path/to/videos PORT=3000 node server.js
```

需要本机装有 `ffmpeg` / `ffprobe`(用于读取时长、分辨率和生成封面)。
